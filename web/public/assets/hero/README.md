# Hero Assets Directory

Use this folder to replace temporary placeholders with final premium media assets.

## Structure
- `3d_render/`  -> static WebP/PNG renders (2K/4K)
- `ai_video/`   -> loopable MP4/WebM videos
- `hifi_mockup/`-> high-fidelity product screenshots/crops (2K+)

## Required filenames
For each mode, provide these three files:
- `gateway`  (`gateway.webp` or `gateway.mp4`)
- `headhunter` (`headhunter.webp` or `headhunter.mp4`)
- `solutions` (`solutions.webp` or `solutions.mp4`)

Current placeholders are generated automatically and should be replaced.
